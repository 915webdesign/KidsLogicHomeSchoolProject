# Repository instructions for coding agents

This is a public, adult-managed learning repository. Write clear, concrete teaching material for a child and an adult. Never add names, ages, locations, photos, private learner work, or identifying stories. Avoid claims that a tutor bot runs automatically unless the repository contains working infrastructure for it.

Prefer one concept per lesson, ordinary materials, a concrete example, an Explorer and Builder variation, and a short check for understanding. Preserve child agency: prompts should ask for the learner's reasoning before offering answers. Do not build account systems, analytics, public child profiles, or automatic publication without an explicit request. Keep links relative within the repository. When editing a lesson, check that its examples and answer key agree.
