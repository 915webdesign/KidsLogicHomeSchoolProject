# LogicKids

A home learning project for children and a parent or teacher. Practice clear thinking, kind disagreement, and good decisions through stories, games, and projects learners choose.

## Start here

1. Read [the parent guide](docs/parent-guide.md).
2. Run [Lesson 1: Claims and reasons](lessons/01-claims-and-reasons.md).
3. Follow [the 12-week path](docs/curriculum.md) for one 25–40 minute session each week.
4. Let each learner choose a project using [the project template](projects/PROJECT_TEMPLATE.md).
5. Use [the AI tutor guide](agents/README.md) to start a coach, questioner, or project guide in separate chats. An adult reviews all AI output and GitHub changes.

No account, public post, code, or purchase is required for a child to participate. This public repository contains teaching materials only. Keep names, ages, photos, answers, locations, and personal stories out of issues and commits.

## Learning goal

Given a claim or decision, a learner can ask what it means, name a reason, check whether the reason supports the claim, consider an alternative, and explain a choice with humility.

The agent instructions are reusable prompts, not continuously running services. An adult starts each role in an AI session and supervises its use.
